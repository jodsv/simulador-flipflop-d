# Simulador de Flip-Flop D

Script em Python desenvolvido para uma dinâmica de aula invertida de Introdução à Computação. O programa demonstra, via terminal, o funcionamento de um Flip-Flop tipo D a partir de uma dinâmica interativa.

## Como Executar

Requisito: Python instalado. Não requer bibliotecas extras

1. Clone o repositório ou baixe o arquivo `jogo_flipflop.py`.
2. Abra o terminal e execute o comando:
   ```bash
   python jogo_flipflop.py
